# 💈 Barbería App — Sistema de Citas y Reservas

Aplicación web interactiva para la reserva de turnos en línea, selección de servicios y gestión de citas con persistencia en tiempo real.

## 🚀 Tecnologías Utilizadas

- **Frontend:** Next.js, JavaScript, Tailwind CSS
- **Backend & Base de Datos:** Supabase (PostgreSQL)
- **Librerías:** `lucide-react` (Iconos)
- **Despliegue:** Vercel

## ✨ Características

- 📅 **Reserva de Turnos:** Selector interactivo de fecha y horario.
- ✂️ **Catálogo de Servicios:** Selección de cortes, barba y tratamientos.
- 🔄 **Sincronización:** Registro inmediato de reservas en Supabase.
- 📱 **Diseño Adaptable:** Interfaz oscura orientada a una experiencia móvil limpia.

## 🛠️ Instalación Local

```bash
# Clonar el repositorio
git clone [https://github.com/jdh100704/barberia-app.git](https://github.com/jdh100704/barberia-app.git)

# Entrar a la carpeta
cd barberia-app

# Instalar dependencias
npm install

# Iniciar en entorno de desarrollo
npm run dev
